# Project Instructions & Preferences

## Testing Policy
- For prototype features, do **NOT** run automated browser tests or subagent tests unless explicitly instructed by the user.
- The user will perform browser testing manually and share screenshots for feedback and adjustments.

## Card Styling & Dimensions
- Card widths and layout dimensions can be adjusted (e.g. `max-w-[360px]`, `max-w-[380px]`, or responsive breakpoints) to match layout requirements.
- **Card Style 4**: Designed as a **Dual-Pane Split Card** with a left gradient accent block (containing calendar icon & year badge) and a clean right pane for title, branch/semester metadata, and download button.
